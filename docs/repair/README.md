## Starting point that was reconciled

- Local folder `nextpractice/nextjs-app` was **not a git repo**. All 125 present files were
  byte-identical to `KhareV/Portfolio@ad7d86a` after stripping CR (Windows line endings);
  `.gitignore` and `.env.example` were missing; `node_modules` was a Windows install
  (`@next/swc-win32-x64-msvc`) that cannot run on macOS. No local edits existed to preserve.
- The repair was developed in a clean clone on branch `repair/reliability` (3 commits on
  top of `ad7d86a`). `repair.bundle` in this folder holds those commits; to get them into
  a clone of the GitHub repo: `git fetch /path/to/repair.bundle repair/reliability:repair/reliability`.
  The files were also copied into this checkout (CRLF line endings, to match it).

## Run it

```bash
npm ci                 # replaces the Windows node_modules
npm run lint           # 0 problems
npm test               # unit: time zones, tier policy, chat contract, GitHub model, stars
npm run build
npm run start          # or: npm run preview  (build + start)
npm run test:e2e       # Playwright; first time: npx playwright install chromium webkit firefox
```

Optional configuration (`.env.local`, see `.env.example`): `GROQ_API_KEY` (server only),
`NEXT_PUBLIC_EMAILJS_*` (public by design), `GITHUB_TOKEN` (server only),
`NEXT_PUBLIC_SITE_URL`. Without them the chat answers from saved notes and the form
offers a prefilled email instead of sending.

Force a visual tier to inspect it: `/?visuals=static|lite|full` (cannot force WebGL that
the browser lacks).

## Architecture after the repair

| Concern | Where |
|---|---|
| All copy, links, projects, experience | `app/content/site.js` (single source; chat fallback reads it) |
| Page, in document order, server-rendered | `app/page.jsx` → `sections/*` |
| Time zone (IST) and day phase | `app/lib/time.js`; inline boot script sets `html[data-phase]` + preloads the plate |
| Visual tier policy (no UA sniffing) | `app/lib/visualPolicy.js`, `app/lib/useVisualTier.js` |
| Renderer isolation | `components/SceneBoundary.jsx`, `lib/preflight.js` (assets fetched before a Canvas mounts) |
| Anchors and focus | `components/AnchorManager.jsx`; `html { scroll-padding-top }` |
| Optimized media | `public/media/**` generated by `npm run media` (`scripts/build-media.mjs`, needs ffmpeg) |
| APIs | `app/api/chat/route.js` (plain-text contract), `app/api/github/route.js` (server token, edge cache) |

Replaced on purpose (features removed or swapped, with reason): blocking loader overlay
(delayed every task, locked body scroll), custom cursor (hid the I-beam), Lenis smooth
scroll (native scroll measured smooth: p95 16.7 ms, 0 frames > 33 ms; keeps native touch
and keyboard behaviour), music prompt modal (auto-opened and blocked clicks — now an
explicit button), Beams background (unreachable), react-globe.gl (leaked rAF loops →
small R3F globe), typed hero heading (empty H1 in HTML), mobile.css.
